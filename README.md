## Estructura de directorios

Existe varias formas de ordenar las carpetas y archivos en un proyecto Frontend, dos formas básicas de estructurar las carpetas son en el estilo **MVC** y también en funcionalidades o **Features**

### MVC
Basado en la estructura Model-View-Controller, en React tendremos unos directorios llamados Styles-Components-Reducers, en donde la carpeta Styles tendría archivos .css, Componenets agruparía archivos .jsx o .tsx y en Redusers se colocarían los archivos .js o .ts

### Features
Forma de organizar las carpetas y archivos orientada en funcionalidades, la cual se basa en crear un directorio que contendrá una funcionalidad completa
